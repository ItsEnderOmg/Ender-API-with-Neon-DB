# Basic User CRUD

## Technologies used

- **Python**
- **FastAPI**
- **PostgreSQL (Hosted with Neon)** 
- **SQLAlchemy**
- **Pydantic**
- **Html/CSS/JavaScript**

## This is a practice project that can:

- [x] Create users in a database
- [x] Read User/s data 
- [x] Update users
- [x] Delete users

It also has errors handling.

## How to use it

### 1. Clone the repository:

```git clone https://github.com/ItsEnderOmg/Ender-API-with-Neon-DB.git```

### 2. Create a .env file and paste your Database's URL
```DATABASE_URL=paste_here```

### 3. Paste your API's URL in the 'script.js'
``` const API_URL = 'YourAPI_URL' ```
